# Руководство: подключение VK → MAX (v2)

## Важно: два независимых этапа
1. n8n принимает событие через узел `VK Community Trigger`.
2. VK отправляет событие только после подтверждения адреса Callback API и включения нужного типа события.

Подтверждение адреса само по себе **не включает события**.

## 1. Установка
На Ubuntu Server 22.04/24.04:

```bash
sudo apt update
sudo apt install -y git screen
sudo git clone https://github.com/nesterovichvmir/MAX-n8n-install.git /opt/MAX-n8n-install
sudo screen -S max-install bash /opt/MAX-n8n-install/v2/install.sh
```

Команду `screen` запускает администратор. Для возврата в отсоединённый сеанс: `sudo screen -r max-install`. Для отсоединения: Ctrl+A, затем D.

Выберите модуль VK → MAX. Введите n8n API Key, токен сообщества VK, Confirmation String, токен MAX и тип получателя:
- личный MAX User ID;
- групповой MAX Chat ID.

Секреты вводятся скрыто. Не отправляйте их в чат и не добавляйте в скриншоты.

## 2. Получение Production URL
1. Откройте n8n → workflow `VK → MAX (v2)`.
2. Откройте узел `VK Community Trigger`.
3. Скопируйте **Production URL**, не Test URL.

## 3. Добавление отдельного Callback API сервера
1. Откройте сообщество VK → Управление → Работа с API → Callback API.
2. Не редактируйте существующий production-сервер. Нажмите «Добавить сервер».
3. Задайте название, например `n8n VK → MAX v2`.
4. Версия API: `5.199`.
5. В поле «Адрес» вставьте Production URL из n8n.
6. Нажмите «Подтвердить». Дождитесь сообщения об успешном сохранении/зелёной галочки.

Confirmation String вводится в Credential `V2 - VK Community` в n8n. Это строка ответа на проверочный запрос VK, а не часть URL.

## 4. Обязательное включение события
1. Оставаясь в настройках **того же нового Callback API сервера**, откройте вкладку «Типы событий».
2. Найдите раздел «Записи на стене».
3. Поставьте галочку «Добавление» — это событие `wall_post_new`.

Если этот флажок выключен, VK не отправляет уведомления о новых постах, даже когда адрес подтверждён и workflow опубликован. Это было причиной первого неудачного теста.

## 5. Проверка
1. Опубликуйте новую запись в тестовом сообществе.
2. В n8n откройте workflow → Executions.
3. Должна появиться новая execution со статусом `Succeeded`.
4. Убедитесь, что сообщение пришло в выбранный MAX диалог/чат.
5. Проверьте отдельно текст, фото и видео.

## 6. Если нет запусков
- Проверьте, что открыли правильный сервер VK, а не старый production-сервер.
- Проверьте зелёную галочку подтверждения адреса.
- Проверьте `Типы событий → Записи на стене → Добавление`.
- Откройте вкладку «Запросы» VK и посмотрите, поступает ли `wall_post_new`.
- В n8n проверьте, что workflow активен/опубликован, а триггер использует `V2 - VK Community`.

## 7. Безопасность
- Не удаляйте и не изменяйте существующий Callback API сервер production.
- Для теста создавайте отдельный Callback API сервер.
- Не публикуйте токены, API Key, Secret Key, резервные копии и N8N_ENCRYPTION_KEY.
- Если Secret Key попал на скриншот или в переписку, замените его в VK и обновите Credential в n8n.
