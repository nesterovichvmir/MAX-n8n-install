# Пошаговая инструкция администратора: VK → MAX

**Назначение:** новые публикации сообщества VK автоматически пересылаются в один групповой чат MAX. Личные сообщения MAX в этом модуле не поддерживаются.

> Важно: подтверждение Callback API и включение события публикации — два разных действия. Если не включить событие «Записи на стене → Добавление», VK не отправит новый пост в n8n.

## Что подготовить заранее

- Ubuntu Server 22.04 или 24.04 LTS.
- Домен n8n с HTTPS, доступный из интернета.
- Токен сообщества VK.
- Confirmation String из настроек Callback API VK.
- Токен MAX-бота.
- **ID группового чата MAX** (не личный ID пользователя).
- Бот MAX уже добавлен в нужный групповой чат.

Не вставляйте токены, API Key и Secret Key в эту инструкцию, скриншоты или переписку.

## Шаг 1. Запустить установщик

Подключитесь к Ubuntu по SSH и выполните команды:

```bash
sudo apt update
sudo apt install -y git screen
sudo git clone https://github.com/nesterovichvmir/MAX-n8n-install.git /opt/MAX-n8n-install
sudo screen -S max-install bash /opt/MAX-n8n-install/v2/install.sh
```

Команду `screen` запускает администратор. Она нужна, чтобы установка продолжилась, даже если PuTTY/SSH отключится.

- В меню выберите **2 — только VK → MAX**, если n8n и модуль СЭМД уже работают.
- Подтвердите добавление модуля в существующий n8n.
- Введите URL n8n, если установщик его запросит.
- Введите n8n API Key. Ввод скрытый.
- Введите токен сообщества VK и токен MAX-бота. Ввод скрытый.
- Введите **числовой ID группового чата MAX**. Не вводите личный User ID.
- Введите Confirmation String из настроек Callback API.
- Если для Callback API задан Secret Key, введите его в соответствующий запрос; если не задан — оставьте поле пустым.

Если SSH-соединение оборвалось, подключитесь снова и вернитесь в установку:

```bash
sudo screen -r max-install
```

Чтобы временно отсоединиться от screen, нажмите Ctrl+A, затем D.

## Шаг 2. Скопировать Production URL из n8n

1. Откройте n8n в браузере.
2. Откройте workflow **VK → MAX (v2)**.
3. Нажмите узел **VK Community Trigger** — это первый узел слева с логотипом VK.
4. В настройках узла найдите **Webhook URLs**.
5. Скопируйте адрес из раздела **Production URL**. Не используйте Test URL.

Этот адрес относится к созданному workflow. Не составляйте его вручную и не копируйте URL из другого узла.

## Шаг 3. Добавить Callback API сервер в VK

1. Откройте нужное сообщество VK.
2. Перейдите **Управление → Работа с API → Callback API**.
3. Откройте вкладку **Callback API**.
4. Нажмите **Добавить сервер**. Для тестирования используйте отдельный сервер; не меняйте существующий рабочий production-сервер.
5. Назовите сервер, например **n8n VK → MAX**.
6. В поле **Версия API** выберите **5.199**.
7. В поле **Адрес** вставьте скопированный в n8n **Production URL**.
8. Нажмите **Подтвердить**.

VK отправит проверочный POST-запрос. Строка из поля Confirmation String должна совпадать со строкой, которую установщик сохранил в Credential **V2 - VK Community**. При успешной проверке VK покажет, что адрес сервера подтверждён/сохранён.

**Не вставляйте Confirmation String в поле «Адрес».** В поле «Адрес» находится только Production URL из n8n.

## Шаг 4. Включить событие публикации — обязательно

1. Не выходя из настроек только что добавленного Callback API сервера, откройте вкладку **Типы событий**.
2. Прокрутите до раздела **Записи на стене**.
3. Поставьте галочку **Добавление**.
4. Убедитесь, что галочка осталась включённой после сохранения настроек.

Это событие VK называется `wall_post_new`. Именно оно сообщает n8n о новой публикации на стене сообщества.

**Если галочка не установлена, workflow не запустится при публикации поста**, даже если адрес сервера успешно подтверждён и workflow в n8n опубликован.

## Шаг 5. Проверить работу

1. Создайте новую тестовую запись на стене сообщества VK.
2. Откройте n8n → workflow **VK → MAX (v2)** → вкладка **Executions**.
3. Дождитесь новой записи о запуске. Успешный запуск отмечается статусом **Succeeded**.
4. Откройте групповой чат MAX и проверьте, что публикация пришла.
5. Отдельно проверьте текстовую публикацию, публикацию с фотографией и публикацию с видео.

Для проверки используйте новую публикацию после включения галочки. Старые посты задним числом не пересылаются.

## Если публикация не пришла

Проверяйте только эти пункты по порядку:

1. В VK открыт именно тот Callback API сервер, URL которого скопирован из Production URL узла VK Community Trigger.
2. Адрес сервера подтверждён.
3. Во вкладке **Типы событий** включено **Записи на стене → Добавление**.
4. Workflow **VK → MAX (v2)** опубликован/активен в n8n.
5. В Credential **V2 - VK Community** указаны действительные токен сообщества, версия API **5.199** и правильная Confirmation String.
6. MAX-бот добавлен в групповой чат, а в установщик был введён ID именно этого чата.

Если в n8n появилась Execution со статусом **Succeeded**, но сообщение не пришло, откройте эту Execution и найдите первый узел с ошибкой или ответ API MAX.

## Важные правила безопасности

- Не изменяйте существующий Callback API сервер, который обслуживает рабочую систему.
- Для отдельного тестового n8n создавайте отдельный Callback API сервер.
- Не публикуйте VK token, MAX token, n8n API Key, Secret Key, пароли и резервные копии.
- Если Secret Key попал в открытый скриншот или переписку, замените его в настройках VK и обновите Credential в n8n.
