# Модуль VK → MAX

Подробная инструкция по установке и настройке модуля VK → MAX находится в общем руководстве администратора:

**[Полное руководство MAX + n8n v2](ADMIN_GUIDE_V2.md)**

Перейдите к разделу **6. Модуль VK → MAX**. В нём описаны:
- подготовка группового чата MAX и назначение бота администратором;
- ввод токена VK, токена MAX, ID группового чата и Confirmation String;
- получение Production URL из узла VK Community Trigger;
- настройка Callback API;
- включение события «Записи на стене → Добавление»;
- проверка доставки публикаций с текстом, фотографиями и видео.
