MAX-n8n-install v2 — modular installer package\n\n- Separate v2 directory; root v1 files and MAX-n8n-install-v6 remain unchanged.\n- Three install choices: SEMD, VK → MAX, or both.\n- Detects existing n8n 2.42.6 and creates a data backup before module changes; other versions are rejected. Saves the external encryption key alongside the archive and refuses unsupported external n8n databases.\n- Existing n8n container and N8N_ENCRYPTION_KEY are not recreated or changed. A container restart may occur after installing a missing community package; no restart is needed when the exact package versions are already loaded.\n- Existing Credentials and workflows are never overwritten.\n- Existing active module workflows are skipped on reruns; inactive same-name workflows stop the installer for manual review. Missing modules can be added separately.\n- VK workflow is based on the latest user-provided VK Max (5)(1).json export.
- VK setup asks for both community access token and Callback API confirmation string; optional secret key is supported.
- Post-install instructions require the administrator to register the trigger Production URL in VK Callback API and enable `wall_post_new`.\n- All three JavaScript Code node scripts are checked byte-for-byte by check_package.py.\n- Target MAX chat ID is parameterized in all three send nodes.\n- Text-only request body in HTTP Request5 is normalized to a valid n8n expression.\n- yt-dlp is installed on the Ubuntu host; dedicated non-sudo SSH account is configured.\n- SSH password persists in a root-only file for repeatability.
- Installer verifies that the n8n container can reach the host SSH service and rejects sudo membership for the dedicated account. SSH provisioning runs only when VK is actually missing; existing user passwords are not reset.
- SEMD registers only the `bot_started` subscription; the workflow registers `message_created` itself, avoiding duplicate subscriptions.\n- Official OS support: Ubuntu Server 22.04/24.04 LTS.\n- Administrator must start installer inside screen; installer does not create screen itself.\n- Run bash -n, py_compile, and check_package.py before install; functional tests on a disposable VM remain mandatory.\n
