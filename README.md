# MAX + n8n — автоматическая установка

Модульный установщик для медицинских организаций. Общая платформа n8n поддерживает два модуля:

- **СЭМД** — отчёты о неподписанных СЭМД и регистрация сотрудников через MAX.
- **VK → MAX** — пересылка новых публикаций сообщества ВКонтакте в групповой чат MAX.

## Актуальная версия

Используйте пакет **v2**:

**[Полное руководство администратора](v2/ADMIN_GUIDE_V2.md)**

**[Описание пакета и требования](v2/README.md)**

## Установка

На Ubuntu Server 22.04/24.04 LTS:

```bash
sudo apt update
sudo apt install -y git screen
sudo git clone https://github.com/nesterovichvmir/MAX-n8n-install.git /opt/MAX-n8n-install
sudo screen -S max-install bash /opt/MAX-n8n-install/v2/install.sh
```

Во время запуска выберите СЭМД, VK → MAX или оба модуля. Установщик запрашивает только параметры выбранных модулей и помечает каждый блок вопросов названием модуля.
