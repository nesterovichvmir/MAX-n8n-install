# MAX + n8n — автоматическая установка

Установщик для развёртывания модулей медицинской организации на базе **n8n**:

- **СЭМД** — отчёты и регистрация сотрудников.
- **VK → MAX** — автоматическая пересылка новых публикаций сообщества VK в групповой чат MAX.

## С чего начать

Для новых установок используйте актуальный модульный пакет **v2**:

**[Открыть пакет v2 и инструкцию](v2/README.md)**

Пошаговая инструкция по подключению VK Callback API:

**[Инструкция VK → MAX](v2/USER_GUIDE_VK_MAX.md)**

## Установка v2

На новой Ubuntu Server 22.04/24.04 LTS или сервере с совместимым n8n 2.42.6:

```bash
sudo apt update
sudo apt install -y git screen
sudo git clone https://github.com/nesterovichvmir/MAX-n8n-install.git /opt/MAX-n8n-install
sudo screen -S max-install bash /opt/MAX-n8n-install/v2/install.sh
```

Перед запуском прочитайте [требования и ограничения v2](v2/README.md).

## Важно

- Для VK → MAX используется **только групповой чат MAX**. Личные User ID не поддерживаются.
- В VK необходимо подтвердить Callback API сервер и отдельно включить событие **Типы событий → Записи на стене → Добавление**.
- Не публикуйте API Key n8n, токены VK/MAX, SQL-пароли и резервные копии.
- Не запускайте установщик поверх работающей системы без резервной копии и понимания выбранного режима.
